The scheduler wakes before the sun does. Issue 188 tracks the whole effort: the residency scheduler promotes the experts that real traffic keeps choosing, and the cold ones stay in pinned memory where the graphics card can read them directly over the bus. Every routed choice counts, hit or miss, and the counters between tokens tell the truth about coverage. A layer whose ten routed experts all live in video memory never publishes a cold job at all, and the report answers three questions per token: how many layers skipped, how many cold experts were touched, how many bytes crossed the wire. The warm-up run walks a long document, accumulates per-layer selection frequencies, promotes the top set per layer, and persists the result next to the model file so the next session starts hot. The cold path pulls weights straight across the bus inside the matrix kernel, no copy stage, no submission, no stall, no speculation, because measurement killed the speculation months ago. The job ring remains for the control plane only: residency swaps, refresh commands, telemetry, and the loud failure when the stager dies. Bandwidth decides which path a layer uses, never a hardcoded table. The loader verifies the whole memory budget with measured numbers and clamps the hot set before it ever clamps the context, because the floor of two hundred thousand tokens is a promise, not a preference.
