The parity harness runs both engines in the same session, one variable at a time, and every number carries its operating point. The oracle never touches the quantized weights; it reads the originals from the checkpoint, one layer at a time, and answers with the only truth that matters: what the mathematics says the hidden state should be. Attention selects its tokens through the sparse indexer, the budget of two thousand and forty-eight blocks decides what the softmax ever sees, and below the budget the selection is dense by construction, which makes the first two thousand tokens a free correctness gate for the whole path. The recurrent layers carry their state forward without a cache to resize, twelve heads of float, fixed and small. Key and value rows land in the cache as eight-bit floats by default and the fallback dtype is a config switch away, never a file format change. The n-gram table never loads in full; the host computes the row indices per token, the cache absorbs the hot rows, and the gather kernel reads whatever slots the index math names. Greedy sampling closes the loop: one matrix-vector product against the untied head, one reduction, one token out, and the trace continues.
