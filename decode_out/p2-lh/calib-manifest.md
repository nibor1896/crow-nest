## Rendering and normalisation

- Sessions: `apply_chat_template(messages, tools=None, tokenize=False)` with the 27B's own template, then `tokenizer(text, add_special_tokens=False)`; one stream per session file. Template defaults kept (enable_thinking/reasoning_effort unset -> the "xhigh" system line; preserve_thinking unset -> every stored `reasoning_content` rendered).
- No tool schemas: the session files store none (Crow sends them per request); same choice as `tools/session_ids.py`. The template therefore renders no `# Tools` block; assistant tool calls are rendered in its `<tool_call><function=...>` form.
- `image_url` parts dropped, text parts joined (text-only calibration; a bare `<|image_pad|>` would have no vision embedding behind it). `tool_calls[].function.arguments` JSON strings parsed to dicts (the template needs `|items`); non-object strings wrapped as `{"raw": ...}`.
